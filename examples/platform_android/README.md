# platform_android — foundation_platform Android example

## Structure (Tauri v2 mobile convention)

```
platform_android/
├── src-tauri/           ← The Rust crate (compiled to .so for Android)
│   ├── Cargo.toml       ← Binary crate, cdylib + staticlib, [workspace] opt-out
│   ├── tauri.conf.json  ← Tauri config with Android identifier
│   ├── build.rs         ← tauri_build::build()
│   ├── public/          ← WebView assets (bundled into APK)
│   ├── src/
│   │   ├── lib.rs       ← #[mobile_entry_point] — shared library entrypoint
│   │   └── main.rs      ← Desktop entrypoint (calls lib::run())
│   └── gen/android/     ← Generated by cargo tauri android init (Gradle project)
│       └── app/build/outputs/apk/  ← Built APKs
├── icons/               ← App icon
└── README.md
```

**Why src-tauri/?** Tauri v2 requires this structure for mobile builds.
The `src-tauri/` crate compiles to a `.so` (Android) or `.a` (iOS) with
`crate-type = ["cdylib", "staticlib"]`. The root level is for workspace
config — the actual binary is always nested.

**Why both lib.rs and main.rs?** `lib.rs` with `#[mobile_entry_point]`
becomes the JNI entrypoint on Android. `main.rs` is the desktop entrypoint
that calls into the same `run()` function. Same code, different entrypoints.

## Run

```bash
# Start emulator (always use 1080x2160 resolution for consistent screenshots)
emulator -avd test_x86_64 -skin 1080x2160 -dpi-device 420 -gpu swiftshader_indirect

# Build and install
JAVA_HOME=/usr/lib/jvm/java-17-openjdk cargo tauri android build --target x86_64
apksigner sign --ks debug.keystore --out signed.apk unsigned.apk
adb install -r signed.apk
```

## Build

```bash
ANDROID_HOME=~/android-sdk cargo tauri android init   # Generate Gradle project
ANDROID_HOME=~/android-sdk cargo tauri android build  # Compile .so + APK
adb install src-tauri/gen/android/app/build/outputs/apk/universal/release/app-universal-release-unsigned.apk
```

**Note:** Always run the emulator at `1080x2160` (`-skin 1080x2160 -dpi-device 420`).
This resolution produces consistent, readable screenshots without excessive zoom.
