Sandbox and agent RPC demo

Each sandbox is its own Durable Object with its own container. Write to a sandbox from its card, or write @name message in the central chat. Each tab shows its own commands, files and evidence.

Running sandboxes: 0

Sandboxes

One card per sandbox. Each card has its own message box.

The three model paths are Cloudflare Workers AI through the Worker's AI binding, OpenRouter through the agent RPC catalog, and a model server that runs inside the sandbox's own container and is reached over its container port. Each answer names its model path, service, address and protocol. The Worker sends these values as response headers.

Local wrangler dev can run one container per Worker process (issue #1221). This demo is a real deploy, so the extra sandboxes only work on the deployed demo.
