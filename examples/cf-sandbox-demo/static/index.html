Sandbox and agent RPC demo

Each sandbox is its own Durable Object with its own container. Each tab runs one command console and one agent conversation, on its own model path.

Running sandboxes: 0

The three model paths are Cloudflare Workers AI through the Worker's AI binding, OpenRouter through the agent RPC catalog, and a model server that runs inside the sandbox's own container and is reached over its container port.

Local wrangler dev can run one container per Worker process (issue #1221). This demo is a real deploy, so the extra sandboxes only work on the deployed demo.
