# Feature 02: VM Communication — Agent Workflow

## Steps

1. **Read `feature.md`** — understand requirements, architecture, and tasks
2. **Read spec-level `LEARNINGS.md`** (parent directory) — design decisions
3. **Read spec-level `VERIFICATION.md`** if exists (parent directory)
4. **Read `features/01-qemu-backend/feature.md`** — understand the QEMU backend API this depends on
5. **Read AGENTS.md** and project skills:
   - `.agents/AGENTS.md`
   - `.agents/skills/rust-clean-code/skill.md`
6. **Generate `compacted.md`** for context optimization
7. **Clear context and reload**
8. **Work on ONE task at a time** from Implementation Phases
9. **Use TDD** — write tests before implementation
10. **Report to Main Agent** when task is complete
11. **Wait for verification**
12. **Delete `compacted.md`** after each commit

## Reminders

- **No coding without reading the spec first**
- **Update LEARNINGS.md after each milestone**
- **feature.md is the single source of truth**
