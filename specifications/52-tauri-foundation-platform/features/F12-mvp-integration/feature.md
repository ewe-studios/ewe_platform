# F12 — MVP integration and demo app

## Overview

Integrate all MVP components into a working Tauri application. Ship a demo app
that exercises the full feature set: boot, routes, navigation, cache, profiles,
capabilities, and the codegen pipeline. This is the "ship it" feature.

All preceding features (F00–F11) must be complete before this starts.

## Requirements

### 1. Demo app: full feature exercise

A Tauri app that demonstrates every MVP capability:

```
platform_demo/
  ├── build.rs              ← foundation_platform::generate_platform_code()
  ├── Cargo.toml
  ├── src/
  │   ├── main.rs           ← #[platform_bin] entrypoint, route registration
  │   ├── generated/        ← auto-generated by build.rs
  │   └── app/
  │       └── mod.rs         ← application logic
  ├── src/bin/              ← auto-generated by build.rs
  └── shell_wasm/           ← compiled wasm artifacts
```

### 2. Route set

```rust
#[platform_bin]
fn main(session: PlatformSession) {
    // Surface 1: Local WebView app
    session.route("/app/*", RouteDecision::webview_app()
        .with_profile(Profile::App));

    // Surface 4: Remote server-driven content
    session.route("/remote/*", RouteDecision::remote_fetch()
        .with_profile(Profile::TrustedRemote)
        .with_cache_policy(CachePolicy::NetworkFirst));

    // Surface 5: Cached offline replay
    session.route("/cached/*", RouteDecision::remote_fetch()
        .with_profile(Profile::TrustedRemote)
        .with_cache_policy(CachePolicy::CacheFirst));

    // Auth flow
    session.route("/auth/*", RouteDecision::remote_fetch()
        .with_profile(Profile::Auth));

    // Camera capability (profile-gated + per-route allowed)
    session.route("/camera/*", RouteDecision::webview_app()
        .with_profile(Profile::App)
        .with_allowed_capabilities(&[CapabilityId::camera]));

    session.register_capability::<CameraCapability>();
}
```

### 4. Tests

```rust
// Full MVP integration test
#[platform_test]
async fn mvp_full_flow() -> Result<()> {
    let session = PlatformTestSession::new();
    
    // 1. Register all routes
    session.route("/app/*", RouteDecision::webview_app().with_profile(Profile::App));
    session.route("/remote/*", RouteDecision::remote_fetch().with_profile(Profile::TrustedRemote));
    session.route("/cached/*", RouteDecision::remote_fetch().with_cache_policy(CachePolicy::CacheFirst));
    
    // 2. Navigate to app screen
    let page = session.navigate("/app/home").await?;
    assert_eq!(page.url().path(), "/app/home");
    
    // 3. Navigate to remote screen
    let page = session.navigate("/remote/dashboard").await?;
    assert_eq!(page.url().path(), "/remote/dashboard");
    
    // 4. Back navigation shows screenshot then loads
    session.back().await?;
    assert_eq!(page.url().path(), "/app/home");
    
    // 5. Offline: cached route still works
    session.go_offline();
    let page = session.navigate("/cached/data").await?;
    assert!(page.content_present());
    
    // 6. Online-only route fails offline
    session.route("/realtime/*", RouteDecision::remote_fetch().with_cache_policy(CachePolicy::OnlineOnly));
    let result = session.navigate("/realtime/data").await;
    assert!(result.is_err());
    
    Ok(())
}
```
