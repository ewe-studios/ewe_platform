# 018 — Event Runtime: Direct binding + MutationObserver auto-cleanup

**Date:** 2026-06-08
**Status:** Resolved

### Decision

**Direct binding is always the default.** `primal:{event}` attaches a listener directly on the target element.

### 1. Direct binding (always the default)

```html
<button primal:onclick="controller.delete">Click</button>
<input primal:onchange="handler.update" />
<form primal:onsubmit="form.submit">...</form>
```

`element.addEventListener(eventType, handler)` — clean `this` context, works for bubbling AND non-bubbling events (focus, blur, scroll, etc.).

### 2. `primal:{event}:delegate="{selector}"` — opt-in delegation

Users can explicitly request delegation:

```html
<button primal:onclick:delegate="#container">Click</button>
<button primal:onclick:delegate="parent">Click</button>
<button primal:onclick:delegate="body">Click</button>
```

Listener is attached to the resolved target, not the element itself.

### 3. MutationObserver auto-cleanup

A single MutationObserver watches for removed nodes and cleans up their listeners:

```js
const elementListeners = new Map();  // element → { eventType: handler, ... }

function wireDirect(element, eventType, handlerRef) {
    const fn = resolveFunctionRef(handlerRef);
    const handler = (e) => fn(e, element);
    element.addEventListener(eventType, handler);
    
    if (!elementListeners.has(element)) {
        elementListeners.set(element, new Map());
    }
    elementListeners.get(element).set(eventType, handler);
}

const observer = new MutationObserver((mutations) => {
    for (const mutation of mutations) {
        if (mutation.type === 'childList') {
            for (const node of mutation.addedNodes) {
                if (node.nodeType === Node.ELEMENT_NODE) scanAndWire(node);
            }
            for (const node of mutation.removedNodes) {
                if (node.nodeType === Node.ELEMENT_NODE) removeListeners(node);
            }
        }
    }
});

observer.observe(document, { subtree: true, childList: true });

function removeListeners(node) {
    const listeners = elementListeners.get(node);
    if (listeners) {
        for (const [type, handler] of listeners) {
            node.removeEventListener(type, handler);
        }
        elementListeners.delete(node);
    }
    for (const child of node.querySelectorAll('[primal]')) {
        removeListeners(child);
    }
}
```

### 4. When MutationObserver is not available

- **Browser cleanup**: When the browser removes a DOM node (e.g., `innerHTML = ""`), its listeners are naturally garbage collected.
- **Our JS removes nodes**: When `foundation-wasm-ui.js` removes nodes (via Arrow batch, etc.), it explicitly registers them with the runtime's removed-node tracking:
  ```js
  function removeNode(node) {
      runtime.trackRemoved(node);  // adds to cleanup queue
      node.parentNode.removeChild(node);
  }
  ```
  The runtime batches removed nodes and cleans up their listeners in a microtask, safeguarding against listener leaks.

### Initial page scan

After `DOMContentLoaded`, the runtime scans the entire document to wire up existing attributes.

### `primal` marker attribute

All elements generated by `html!` get a `primal` attribute on the Rust side. This identifies framework-managed elements for cleanup traversal.

### Programmatic event binding helpers

The runtime provides helper methods for programmatic binding:

```js
// Bind events programmatically
runtime.onclick(element, "controller.delete");
runtime.onchange(element, "handler.update");
runtime.on(element, "custom-event", "custom.handler");

// Delegate programmatically
runtime.onclick(element, "controller.delete", { delegate: "#container" });
runtime.on(element, "click", "controller.delete", { delegate: "parent" });

// Unbind programmatically
runtime.off(element, "click");
```

```js
// Implementation
const runtime = {
    on(element, eventType, handlerRef, options = {}) {
        if (options.delegate) {
            const target = resolveDelegateTarget(element, options.delegate);
            target.addEventListener(eventType, (e) => {
                if (e.target === element || element.contains(e.target)) {
                    const fn = resolveFunctionRef(handlerRef);
                    if (fn) fn(e, element);
                }
            });
        } else {
            wireDirect(element, eventType, handlerRef);
        }
    },
    
    off(element, eventType) {
        const listeners = elementListeners.get(element);
        if (listeners && listeners.has(eventType)) {
            element.removeEventListener(eventType, listeners.get(eventType));
            listeners.delete(eventType);
        }
    },
};

// Convenience methods for common events
["click", "change", "submit", "keydown", "keyup", "focus", "blur", "scroll"].forEach(event => {
    const method = `on${event.charAt(0).toUpperCase() + event.slice(1)}`;
    runtime[method] = (element, handlerRef, options) => {
        runtime.on(element, event, handlerRef, options);
    };
});
```

### Why this design

- **Attribute-based** (`primal:onclick`) — declarative, auto-discovered by MutationObserver
- **Programmatic** (`runtime.onclick`) — for scripts, dynamic elements, conditional binding
- **Same cleanup** — both go through `elementListeners` map, cleaned up by MutationObserver

### Why this design

- **Direct listeners** — works for ALL events, including non-bubbling ones (focus, blur, scroll)
- **Clean `this` context** — `this` is always the element
- **MutationObserver cleanup** — no listener leaks when nodes are removed
- **Runtime tracking** — our own DOM ops explicitly clean up, even without MutationObserver
- **Browser fallback** — natural GC handles edge cases when neither is available
