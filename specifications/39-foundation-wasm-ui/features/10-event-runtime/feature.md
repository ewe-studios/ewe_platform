# Feature 10: Event Runtime

## Description

Event binding system: direct binding as default (`primal:onclick`), opt-in delegation (`primal:onclick:delegate`), MutationObserver for auto-cleanup of non-island content. Programmatic helpers via `primal.on()`.

**Decision:** 018

## Module

`crates/foundation_wasm_ui/assets/foundation-wasm-ui.js` (event runtime)

## Direct binding (default)

```html
<button primal:onclick="controller.delete">Click</button>
<input primal:onchange="handler.update" />
<form primal:onsubmit="form.submit">...</form>
```

`element.addEventListener(eventType, handler)` — clean `this` context, works for bubbling AND non-bubbling events (focus, blur, scroll).

## Opt-in delegation

```html
<button primal:onclick:delegate="#container">Click</button>
<button primal:onclick:delegate="parent">Click</button>
<button primal:onclick:delegate="body">Click</button>
```

Listener attached to resolved target, not the element itself.

## MutationObserver — non-island only

```javascript
const observer = new MutationObserver((mutations) => {
    for (const mutation of mutations) {
        if (mutation.type === 'childList') {
            for (const node of mutation.addedNodes) {
                if (node.nodeType === Node.ELEMENT_NODE && !node.closest('island')) {
                    scanAndWire(node);
                }
            }
            for (const node of mutation.removedNodes) {
                if (node.nodeType === Node.ELEMENT_NODE && !node.closest('island')) {
                    removeListeners(node);
                }
            }
        }
    }
});
observer.observe(document, { subtree: true, childList: true });
```

**Boundary rule:** MutationObserver explicitly skips any subtree rooted at `<island>`. WASM-injected content with `<island>` tags is fully delegated to the browser's custom element lifecycle.

**NOT responsible for:**
- `<island>` content — islands handle their own via `connectedCallback`
- Event delegation — delegated events don't need per-element cleanup
- Server-rendered content — handled by initial `DOMContentLoaded` scan

## When MutationObserver is not available

- **Browser cleanup**: When DOM node removed (`innerHTML = ""`), listeners are naturally GC'd
- **Our JS removes nodes**: `runtime.trackRemoved(node)` → batched cleanup in microtask

```javascript
function removeNode(node) {
    runtime.trackRemoved(node);
    node.parentNode.removeChild(node);
}
```

## Initial page scan

After `DOMContentLoaded`, runtime scans entire document to wire up existing `primal:on*` attributes.

## `primal-id` marker attribute

All elements generated by `html!` get `primal-id` attribute. Serves as both unique lookup key for DOM operations and marker for framework-managed elements.

## Programmatic event binding

```javascript
runtime.on(element, "click", "controller.delete");
runtime.on(element, "click", "controller.delete", { delegate: "#container" });
runtime.off(element, "click");

// Convenience methods
runtime.onclick(element, "controller.delete");
runtime.onchange(element, "handler.update");
```

## Implementation

```javascript
const runtime = {
    on(element, eventType, handlerRef, options = {}) {
        if (options.delegate) {
            const target = resolveDelegateTarget(element, options.delegate);
            target.addEventListener(eventType, (e) => {
                if (e.target === element || element.contains(e.target)) {
                    const fn = resolveFunctionRef(handlerRef);
                    if (fn) fn(e, element);
                }
            });
        } else {
            wireDirect(element, eventType, handlerRef);
        }
    },
    off(element, eventType) {
        const listeners = elementListeners.get(element);
        if (listeners && listeners.has(eventType)) {
            element.removeEventListener(eventType, listeners.get(eventType));
            listeners.delete(eventType);
        }
    },
};

// Convenience methods
["click", "change", "submit", "keydown", "keyup", "focus", "blur", "scroll"].forEach(event => {
    const method = `on${event.charAt(0).toUpperCase() + event.slice(1)}`;
    runtime[method] = (element, handlerRef, options) => {
        runtime.on(element, event, handlerRef, options);
    };
});
```

## Testing

- Direct binding: click → handler called with correct `this`
- Delegation: click on child → handler on parent called
- MutationObserver: added element → wired, removed element → cleaned
- MutationObserver skips island subtree
- Programmatic: runtime.on / runtime.off work correctly
- Initial scan: existing attributes wired on DOMContentLoaded
- Non-bubbling events (focus, blur) → direct binding works
