# Feature 03: Bootstrap & Build Pipeline — Agent Workflow

## Steps

1. **Read `feature.md`** — understand requirements, architecture, and tasks
2. **Read spec-level `LEARNINGS.md`** (parent directory)
3. **Read spec-level `VERIFICATION.md`** if exists
4. **Read upstream features**:
   - `features/01-qemu-backend/feature.md` — QEMU backend API
   - `features/02-vm-communication/feature.md` — SSH/WinRM APIs
5. **Read AGENTS.md** and project skills:
   - `.agents/AGENTS.md`
   - `.agents/skills/rust-clean-code/skill.md`
6. **Generate `compacted.md`**
7. **Clear context and reload**
8. **Work on ONE task at a time**
9. **Use TDD**
10. **Report to Main Agent** when complete
11. **Wait for verification**
12. **Delete `compacted.md`** after commit

## Reminders

- **No coding without reading the spec first**
- **Update LEARNINGS.md after each milestone**
- **feature.md is the single source of truth**
