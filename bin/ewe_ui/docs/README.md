# Ewe user interface operations

The Ewe user interface (UI) command creates, builds, and runs applications.
Use these manuals for generated applications and the shared Todo example.

| Manual | Use it to |
| --- | --- |
| [Running](operations/running.md) | Create a project, start a device, or run the Todo example. |
| [Building](operations/building.md) | Select build tools, find outputs, and check builds. |
| [Publishing](operations/publishing.md) | Prepare, approve, publish, and verify framework packages. |

Start with the [command and application task introduction](../README.md).
