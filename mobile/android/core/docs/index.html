Ewe UI core

NodeStore(timer) creates a screen with root identifier 1. Call receive(frame) on the main thread. It returns true on acceptance. Read reports for row errors.

EventBridge.send(event, node, value, checked) reads the action reference and signed state from that control. The bridge sends these values to ActionCore.trigger. An immediate reply goes back to the store.

LiveMountHost opens a channel when its live node is attached. It closes the channel when the node is removed. Supply a ChannelFactory for your transport.

Use snapshotJson() to compare the current store with a Rust reference fixture. Snapshots contain state lengths. The event bridge retains the original state bytes.
