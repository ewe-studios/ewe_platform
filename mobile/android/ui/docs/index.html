Ewe UI Compose renderer

Call EweScreen(store, bridge) in your Compose content. It reads the root record and observes the state of each displayed child.

Supply imageLoader for images and webView for a mounted web surface. Applications can also supply color and font token resolvers.

BehaviourRegistry.standard supplies dialog, dismiss, transition and scroll lock bindings. Register application behaviours by name. Pass the same registry to the screen and use its supports method when building the store.

OkHttpChannelFactory reads HTTP frames from a size-prefixed stream, receives socket binary messages and decodes base64 event-stream messages. The maximum frame size defaults to four mebibytes.
