Ewe UI binding

CoreBinding(native, store, scope) adapts the generated UniFFI NativeCore to the Kotlin ActionCore interface. Supply a main-thread coroutine scope.

Use hello() for negotiation. Deliver the reply to the node store. Use EventBridge for action requests. A later frame from a native callback enters the same store through the supplied scope.

close() removes the frame listener and releases the native object. The Android archive contains ARM64 and x86-64 native libraries.
