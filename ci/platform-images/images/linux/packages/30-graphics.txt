# Graphics without a GPU: OpenGL/EGL/GLES (WebGL), Vulkan (wgpu, WebGPU,
# llama.cpp's Vulkan backend) and a virtual X server, all running on Mesa's
# software drivers (llvmpipe for GL, lavapipe for Vulkan). The image sets
# VK_ICD_FILENAMES/LIBGL_ALWAYS_SOFTWARE so these are what gets picked; see
# the README for running on a real GPU instead.

mesa-vulkan-drivers
